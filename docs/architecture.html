Factory Inventory Management System

Architecture overview of a full-stack demo application: a Vue 3 single-page app served by Vite, backed by a Python FastAPI service that serves in-memory mock data loaded from JSON files. There is no database.

Startup sequence

1uv run python main.py imports mock_data, which reads all JSON files once.
2Uvicorn binds to 0.0.0.0:8001.
3npm run dev starts Vite on port 3000 with the Vue plugin.
4Browser loads main.js: router + App mount; locale restored from localStorage.

Observations

Things found during the investigation that are worth knowing about.

Client calls endpoints the server does not implement api.js defines getTasks, createTask, deleteTask, toggleTask (/api/tasks) and createPurchaseOrder, getPurchaseOrderByBacklogItem (/api/purchase-orders). None exist in main.py, so these return 404. App.vue calls getTasks() on load and logs the error. The Pydantic models PurchaseOrder and CreatePurchaseOrderRequest are defined but unused.
Backlog view is not routed views/Backlog.vue exists but has no route in main.js; backlog data appears only through the Dashboard.
Inconsistent HTTP access Reports.vue imports Axios and hard-codes http://localhost:8001 instead of going through api.js. The API base URL is also hard-coded in api.js rather than read from an environment variable.
Demo-grade assumptions Quarters are hard-coded to 2025; month filtering uses substring matching on order_date; CORS allows all origins with credentials; data is read-only and resets on restart. All are fine for a local demo but would need changes for production.
